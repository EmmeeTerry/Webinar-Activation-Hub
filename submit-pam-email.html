Prepare a reusable PAM email template

Paste a formatted email from Outlook or import an HTML email. Keep clickable links attached to the right words.

Important: The PAM Hub is on public GitHub Pages. Only prepare material approved for public hosting here. Do not upload private partner communications or confidential information.

Outlook .oft and .msg files are supported when an HTML body is stored in the file. Conversion runs in your browser; if the file has only RTF, use Outlook Save As HTML instead.

Converted template preview

This converts each hyperlink to a labeled link that the PAM Hub can render as clickable text in formatted Outlook drafts.

Publish to the shared repository

Once the submission file is downloaded, a GitHub repository collaborator can upload it to the pam-email-submissions folder. The repository workflow validates and publishes it into the existing PAM email library automatically. This is a temporary handoff until an approved internal upload connector is available.
