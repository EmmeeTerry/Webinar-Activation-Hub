How to use this builder
  1. Select one or more email templates. Each CTA automatically links to its own email inside the PAM Email Hub.
  2. Optionally add a LinkedIn post URL. We add the reshare link automatically. Review the announcement preview and open its links to confirm they work for your audience.
  3. For a SharePoint news post sent by email: Copy the title and formatted body. Open the SharePoint news template and create a new news post from the template. Paste into a native Text web part. Do not use an iframe for an emailed article.
  4. For a SharePoint web page: Use Generate embed code and paste it into an Embed web part. The code captures your selections and text. No separate image or manual linking is required.

The builder prepares the content. Publishing, approval, and sending happen in SharePoint.
