How to use this builder (start here)
  1. Select the email templates you want to announce. Use Recently added or All templates. Avoid selecting an entire large batch if the announcement would become overwhelming.
  2. Review every description. The summaries are draft excerpts from email content, not fact-checked AI summaries. Edit them to explain why PAMs should share each template with partners.
  3. Optional LinkedIn reshare: Paste the URL of an existing approved LinkedIn post. Readers get a direct link to open and reshare the original post. The builder does not create or publish LinkedIn posts.
  4. Choose your publishing method: For SharePoint News sent by email, copy the title and formatted body into a native SharePoint news post (Made for email). Never use an iframe for emailed news. For a SharePoint web page, use the optional iframe embed code below in an Embed web part.
  5. Verify and publish: Open the selected email links and LinkedIn post, confirm the summaries and SharePoint preview, obtain approval, then publish from SharePoint. Nothing is auto-published or emailed.

Optional: Embed the branded announcement on a SharePoint web page

Only for SharePoint web pages, not emailed news. This creates a live iframe displaying the announcement you reviewed. The link references the current PAM templates, so their content is not duplicated.

In SharePoint, edit the intended page, add an Embed web part, paste this code, and preview the page. Do not use an iframe in a news post being sent by email. Regenerate the code if you edit the announcement.

Publishing steps: Open SharePoint and create a new News post using a Made for email template. Copy the headline and formatted body into native SharePoint text. Confirm all links in the news preview, obtain approval, then publish and send through SharePoint. This builder never publishes automatically.
